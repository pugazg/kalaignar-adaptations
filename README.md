# Kalaignar Adaptations

Archival repository for literary adaptations and creative recastings by **M. Karunanidhi (Kalaignar)**.

## Active work

### தாய் காவியம்

`works/thaai-kaaviyam/`

Kalaignar's Tamil poetic adaptation of Maxim Gorky's *Mother*.

The controlling source is a single bibliographic work represented operationally by multiple split PDFs. Split PDFs are provenance/access units only; they are **not** separate works or volumes.

## Source-preservation policy

- Rendered source scans are the controlling textual and structural authority.
- OCR, parsed text, external editions and model memory are never source authority.
- Overall `scan_page` numbering is continuous across split PDFs.
- `part_page` records the local page number inside a supplied split.
- Source PDFs are not committed unless the repository policy is explicitly changed.
- Every physical scan receives one page-aligned archival record during Pass 1.
- `verified` is assigned only after the required direct source-verification passes close.

See `THAAI_KAAVIYAM_ARCHIVAL_GUIDELINES.md` and `NEXT_CHAT_PROMPT_THAAI_KAAVIYAM.md`.
